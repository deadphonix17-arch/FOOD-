Build: install JDK 17, then in this folder run `gradle build` (or add the Gradle wrapper first: `gradle wrapper --gradle-version 8.5`, then `./gradlew build`).
Output jar: build/libs/butchersdelightfoods-fabric-addon-1.0.0.jar -> put in your mods folder next to Butcher's Delight.
Textures are reused from Butcher's Delight; goat and llama cuts use placeholder icons.
